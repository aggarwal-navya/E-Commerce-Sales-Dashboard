# E-Commerce Sales & Performance Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyze e-commerce sales performance and customer behavior.

## Tools Used
- SQL (MySQL)
- Power BI
- Excel/CSV

## Key Metrics
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value

## Dashboard Features
- Revenue by Category
- Monthly Revenue Trend
- Top Products Analysis
- Payment Method Analysis
- Order Status Analysis
- Revenue by City
- Interactive Filters & Slicers

- ecommerce_queries.sql
